[1] invariant coordinates from dimensional analysis (Buckingham-Pi):
    thrust = C * density*angular_speed^2*diameter^4  * f(density*velocity^4 / (thrust*angular_speed^2))
    => two groups: Ct = thrust/(rho n^2 D^4)   and   J = V/(n D).  These are the invariant space.

READING IT: thrust across a 4-in to 20-in propeller and 2500-7000 rpm spans orders of magnitude,
yet at the SAME advance ratio J every one has the SAME Ct. So thrust is NOT a function of the
geometry (D) or speed (n,V) separately - it is the single curve Ct(J), scaled by rho n^2 D^4.
That curve IS the function in its invariant space: 1-D, fully seeable, solvable once for all sizes.
This is f(g(h(D,n,V))): h -> J, g -> Ct(J), f -> the scaling. dia/pitch live inside h and the shape.

HONEST BOUNDS: fixed blade shape, induced velocity & Reynolds ignored -> the collapse is exact by
dynamic similarity. Add Re and Ct = Ct(J, Re): a surface, not a perfect curve (the drag-vs-viscosity
lesson again). Dimensional analysis found the GROUPS mechanically; the CURVE Ct(J) still needs the
physics/data - and DISCOVERING a NONLINEAR intermediate g from data alone (no given dimensions) is
the piece still unbuilt (latent-coordinate / autoencoder+SINDy territory).
